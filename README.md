🤖 [Прототип] Voice-bot: Подтверждение доставки карт СберБизнеса
Концептуальный прототип (PoC) консольного симулятора голосового робота для обзвона клиентов с целью подтверждения доставки бизнес-карт. Решение демонстрирует гибридный подход: жесткое управление диалогом через конечный автомат (FSM) в связке с извлечением намерений (NLU) посредством LLM (GigaChat).

✨ Особенности архитектуры
Гибридный NLU (Rules + LLM): Простые ответы («да», «нет», «1», «2») обрабатываются мгновенно через регулярные выражения. Сложные и нестандартные фразы отправляются в GigaChat для классификации интентов. Это экономит время и токены.
Управление слотами в реальном времени (SQLite): База данных ведет учет временных окон доставки. При предложении вариантов слот переходит в статус HOLD (бронь), чтобы другие клиенты не могли его занять. При отмене или завершении - статус возвращается в FREE.
Генерация ответов по шаблонам: Робот не генерирует ответы нейросетью, а использует готовые фразы (TEMPLATES). Это исключает галлюцинации и гарантирует юридически корректные формулировки.
Встроенный дашборд метрик: После прогона всех сценариев скрипт выводит Conversation Rate (CR), Cancellation Rate, среднее время диалога (AHT) и количество фоллбэков.

🧩 Как это работает (FSM)
Диалог строится на конечном автомате с состояниями:

AWAIT_CONFIRM - ожидаем подтверждение/отказ доставки.
AWAIT_FINAL_REJECT - клиент отказался, предлагаем преимущества или отмену.
AWAIT_SLOT_CHOICE - предложили 2-3 варианта слотов, ждем выбор.
AWAIT_SLOT_CONFIRM - предложили 1 вариант, ждем да/нет.
AWAIT_SLOT_CLARIFY - клиент сказал "давайте", но не уточнил номер варианта.
FINISHED - конец диалога.

📋 Тестируемые сценарии
В скрипте hardcoded 10 энд-ту-энд сценариев, которые прогоняются автоматически:

Хэппи-пас (подтверждение).
Двойной отказ → Отмена.
Конфликт слотов: перенос и выбор конкретного времени (клиент 1).
Конфликт слотов: перенос (клиент 2 занимает другой слот).
Клиент заявляет, что карту не заказывал.
Оффтоп (вопрос про кэшбэк) → гибкий перенос на вечер.
Грубость клиента → Отмена.
Перенос → выбор слота по слову ("второй вариант").
Слоты не подошли → пагинация (следующая пачка слотов) → выбор.
Отказ → преимущества → перенос на конкретную дату → подтверждение единственного слота.
